# Vertex tax Payment Fraud Analytics & Risk Strategy Optimization

This project demonstrates how a Fraud Analytics team at a fintech company can:

- Detect fraudulent transactions
- Optimize approval rates
- Reduce chargebacks
- Segment customer risk
- Monitor fraud KPIs
- Support machine learning strategy decisions

## Tech Stack

- Python
- SQL
- Pandas
- Scikit-Learn
- XGBoost
- Power BI
- Jupyter Notebook

## Project Goals

1. Build fraud monitoring framework
2. Develop risk segmentation strategy
3. Train fraud detection models
4. Optimize fraud score thresholds
5. Analyze fraud vs customer conversion tradeoffs
6. Create executive dashboards
